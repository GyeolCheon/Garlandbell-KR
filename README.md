# 한국 갈론드 벨 (Korean Garland Bell)

파이널판타지14 한국 서버용 채집·낚시 출현 타이머. 어떤 노드가 언제·어디서 뜨는지
에오르제아 시간으로 알려주는, 딱 그 기능만 하는 가벼운 도구입니다.

2019년 이후 멈춰 있던 한국판([Ariette](https://github.com/Ariette/garlandbell))을
원작자가 소스를 공개하며 다른 개발자의 계승을 권한 뜻에 따라 되살린 비영리 팬 포크예요.
황금(7.x) 데이터를 더하고 UI를 리뉴얼했습니다. 올인원 툴이 부담스러운 분을 위한
가벼운 단일 목적 대안을 지향합니다.

🔗 **https://gyeolcheon.github.io/Garlandbell-KR/**

## 주요 변경
- 황금(7.x) 채집 노드 30종 추가 (공식 한국어명)
- 모던 다크/라이트 테마 + 토글
